Markdown 常用数学符号整理

样式

公式位置

行内模式式使用$...$，在文本之间插入公式；显示模式$$...$$，在单独的一行使用。

上标、下标

上标： ^，下标：_。
示例： C_n^2 为 Cn2 。
前置上下标 {}_1^2\!C_3^4 为 12C34 。

分组

把相同等级的表达式放到一起。
符号： {}
如 e^{10} 显示为 e10 ，而 e^10 则为 e10 。

阵列

语法： $$\begin{array}…\end{array}$$，r右对齐，l左对齐，c居中，|垂直线，\hline横线，\\换行，元素之间以&间隔。

示例：

nLeftCenterRight10.2411252−1189−83−2020001+10i

矩阵

语法： $$\begin{matrix}…\end{matrix}$$，每行以\\结尾，元素之间以&间隔。

示例：

1xx21yy21zz2

添加括号：

  • pmatrix()
  • bmatrix[ ]
  • Bmatrix{ }
  • vmatrix| |
  • Vmatrix∥ ∥

等式对齐

语法： \begin{align}…\end{align}，每行以\\结尾，元素之间以&间隔。

示例：

37=732−1122=732122⋅732−1732=732122732−1732=73121−1732≈7312(1−12⋅732)

语法： \begin{cases}…\end{cases}，每行以\\结尾，元素之间以&间隔。

示例：

f(n)={n/2,if n is even3n+1,if n is odd if n is even:n/2if n is odd:3n+1}=f(n)
