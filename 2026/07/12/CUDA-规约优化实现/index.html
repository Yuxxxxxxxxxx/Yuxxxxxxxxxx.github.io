CUDA 规约优化实现

归约（Reduction）是并行计算中的经典操作，例如对数组求和。在 CUDA 中，由于 GPU 的 SIMT 架构，实现高效的归约需要充分考虑线程协作、内存层次和同步开销。本文将基于一份示例代码，逐步实现 CUDA 归约的优化。

问题：把 N=256M 个 float 加在一起。理想带宽利用 = N×4 字节 / 时间 / peak。

一、实现一：divergent 版

判断条件 tid % (2*s) == 0 让 warp 内每次只活 1/2、1/4 … 的 lane → warp divergence。

二、实现二：顺序地址

每 warp 全员活动直到 s = 16，分歧大幅减少；同时访问也 coalesce。

三、实现三：启动减半 + 每 thread 加两元素

kernel launch 开销摊薄一半；同时让算术与内存比例上升。

四、实现四：展开最后一个 warp（去掉无用 sync）

五、warp shuffle

性能采集表：

版本 关键改动 时间 带宽
v1 原始 0.117 ms 1.4 GB/s
v2 sequential addressing 0.045 ms 3.6 GB/s
v3 每 thread 加 2 个 0.038 ms 4.3 GB/s
v4 unroll last warp 0.035 ms 4.7 GB/s
v5 warp shuffle 0.031 ms 5.1 GB/s
