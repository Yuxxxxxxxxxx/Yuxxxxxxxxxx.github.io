Linux驱动——MISC驱动

一、MISC驱动简介

misc——miscellaneous，译为杂项。众所周知，Linux 中的驱动是分层设计的，每个设备都有自己的归属类型，比如键盘为输入设备，属于 input 子系统。但是会存在一些设备无法简单被划分到某一类中，此时可以基于 misc 驱动框架实现该设备的驱动。misc 驱动为不知类型的设备提供一个框架，方便对应设备驱动的开发。

MISC 驱动框架特点：

  1. misc 驱动为字符设备驱动；
  2. 主设备号为 10；
  3. 简单易用。无需主动调用 register_chrdev_region()、cdev_add() 等函数，只需调用 misc_register() 即可完成次设备号的分配和设备文件的创建工作；
  4. 使用 platform 总线实现 misc 驱动和设备的绑定。

上一篇讲了字符设备驱动，MISC驱动可以看成字符设备驱动的一个“轻量封装”：

MISC 不是要和字符设备并列的新机制，它本质上仍然是字符设备。只是很多简单字符设备共享同一个主设备号 10，内核帮你管理次设备号和 /dev 节点。
